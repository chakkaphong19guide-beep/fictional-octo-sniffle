SCRIPT VAULT — รุ่นคลังส่วนกลาง

สิ่งที่ทำได้
- ทุกคนที่เปิดเว็บไซต์เห็นสคริปต์ชุดเดียวกัน และคัดลอกได้
- เฉพาะผู้ที่ใส่รหัสแอดมินถูกต้องเท่านั้นจึงเพิ่ม/แก้ไข/ลบสคริปต์ได้
- บันทึกลง Netlify Blobs ซึ่งเป็นพื้นที่เก็บข้อมูลส่วนกลาง ไม่ใช่ localStorage ของเครื่องใดเครื่องหนึ่ง
- มีค้นหา ดูโค้ดเต็ม คัดลอก รีเฟรช และแก้ไขสคริปต์

สำคัญ: ไฟล์ ZIP นี้เป็นโปรเจกต์พร้อมนำไปเผยแพร่ แต่ยังไม่ใช่เว็บไซต์ออนไลน์จนกว่าจะนำขึ้น Netlify และตั้งค่ารหัสผ่าน/ความลับในขั้นตอนด้านล่าง

วิธีเผยแพร่ให้ทุกคนใช้งานร่วมกัน
1. โปรเจกต์นี้ตั้งรหัสแอดมินไว้ในฟังก์ชันฝั่งเซิร์ฟเวอร์แล้ว ไม่ต้องตั้ง ADMIN_PASSWORD / ADMIN_SECRET ซ้ำ
2. เพื่อให้ฐานข้อมูลส่วนกลางทำงาน ต้องเผยแพร่โปรเจกต์นี้บน Netlify (ฟังก์ชันและ Netlify Blobs จะทำงานบนโฮสต์ ไม่ทำงานเมื่อเปิด index.html จากเครื่องโดยตรง)
3. สร้าง repository ส่วนตัว (Private) บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ script-vault-shared จากนั้นใน Netlify เลือก Add new site / Import an existing project และเชื่อมต่อ repository นี้
4. กด Deploy site รอให้เสร็จ แล้วเปิด URL ที่ Netlify ให้มา
5. ทดสอบเพิ่มสคริปต์หนึ่งรายการ แล้วเปิด URL เดียวกันบนอุปกรณ์อื่นเพื่อตรวจว่ารายการปรากฏเหมือนกัน

หมายเหตุ
- ห้ามเปิดไฟล์ index.html ด้วยการกดเปิดจากเครื่องโดยตรง เพราะ API ต้องทำงานบน Netlify
- ถ้าเปลี่ยน ADMIN_SECRET เซสชันแอดมินเก่าจะใช้ไม่ได้ ต้องเข้าสู่ระบบใหม่
- ทุกคนดูสคริปต์ได้ แต่เฉพาะแอดมินแก้ไขข้อมูลได้
- โปรเจกต์นี้ไม่ทำให้โค้ดสคริปต์ปลอดภัยขึ้นเอง ควรตรวจสอบโค้ดก่อนเผยแพร่
